Frequently Asked Questions

What does the kit generate?

Normalized competitor data, comparison matrices, pricing observations, a source/provenance ledger, an executive Markdown brief and a machine-readable summary.

Does it invent prices or missing facts?

No. Blank or unavailable information remains blank rather than being represented as verified evidence.

Does it need a paid API?

No paid API is required by the core package.

Does it require third-party Python packages?

No. The core product uses the Python 3 standard library.

Is the example data real?

No. Public examples are synthetic demonstrations and are explicitly labeled as such.
